# DP MODULE Sales Configurator — MVP

Это первый рабочий прототип внутреннего конфигуратора отдела продаж.

## Что уже есть

- готовые проекты;
- режим индивидуального проекта;
- калькулятор;
- данные из эталонного КП «Модерн 60»;
- структура индивидуального КП «Канада 24»;
- клиентские данные;
- фундамент / доставка / монтаж;
- предупреждения для индивидуальных расчётов;
- генерация печатной версии КП через браузер (Print → Save as PDF);
- сохранение черновика в localStorage;
- официальные ссылки на страницы фотографий проектов DP MODULE.

## Важно по фотографиям

В MVP карточки ведут на официальные страницы DP MODULE с фотографиями конкретных проектов. Точные файлы изображений с сайта не копируются в этот архив автоматически: перед production-развёртыванием их следует скачать/подключить с разрешённым способом использования и положить в `assets/`.

Источники:
- https://dp-m.ru/modern/tproduct/644444137-833844620081-modern-60
- https://dp-m.ru/canada/tproduct/641429306-894712055061-kanada-60
- https://dp-m.ru/scandinavian/tproduct/644374648-665194680961-skandinaviya-24

## Эталонные документы

- «Канада 24» — индивидуальное КП пользователя.
- «Модерн 60» — КП пользователя.

Они используются как эталон структуры и логики будущего PDF.

## Запуск

Просто откройте `index.html` в браузере.

Для production следующим этапом нужно:
1. перенести каталог в PostgreSQL/Supabase;
2. сделать админку цен и правил;
3. подключить реальные изображения в `assets/`;
4. сделать полноценный PDF renderer;
5. добавить авторизацию, CRM, версии КП и аудит изменений.
