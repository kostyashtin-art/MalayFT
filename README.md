# DP MODULE Sales Configurator v4

GitHub Pages версия внутреннего конфигуратора DP MODULE.

## Что перенесено

Каталог домов и бань из `Katalog_dp-m_Ekb_Tyum_Perm_Ufa.pdf`: серии, модели, площади, габариты и цены. В интерфейсе есть отдельные вкладки домов, бань и готовых комплексов.

Дополнительные опции занесены только при наличии точной суммы в эталонном КП «Модерн 60»: изменение габаритов, высоты, терраса, навес, покраска, тёплый пол, плитка, душевой поддон, климат, закладные, сантехника, лестница и перила.

## Доставка / фундамент / монтаж

Из загруженных документов подтверждены:
- доставка 230 000 ₽ в конкретном КП «Модерн 60»;
- свайно-винтовой фундамент 220 000 ₽ в этом же КП;
- монтаж 300 000 ₽ в этом же КП;
- бесплатные установка и монтаж в пределах 70 км от производства в Екатеринбурге и Новосибирске (каталог).

Отдельной таблицы тарифов «город → доставка» в загруженных документах нет. Поэтому в конфигураторе нет выдуманных тарифов по городам: можно выбрать документный пример 230 000 ₽ или ввести согласованную сумму вручную.

## GitHub Pages

Удалите старые workflows и оставьте только `.github/workflows/deploy.yml`.

GitHub → Settings → Pages → Source → GitHub Actions.
