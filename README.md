# DP MODULE Sales — этапы 1–3

Рабочий прототип конфигуратора для отдела продаж DP MODULE, подготовленный под GitHub Pages.

## Этап 1 — каталог

- Дома / Бани / Готовые комплексы / Свой проект.
- Серии и карточки моделей.
- Точные площадь, габариты и базовые цены, внесённые из загруженного каталога PDF.
- Планировки и изображения моделей локально в `public/assets`.
- Окно подробностей с планировкой и кнопкой «Собрать КП».

## Этап 2 — калькулятор

- Выбор готового проекта.
- Для «Модерн 60» — документные варианты высоты 2700 / 3300 / 3400 / 3500 мм.
- Документные дополнительные опции из КП «Модерн 60».
- Автоматический пересчёт базы + опций.
- Ручные согласованные позиции для параметров, цены которых нет в документах.
- Для остальных моделей точные доплаты не придумываются: используется ручная согласованная позиция.

## Этап 3 — логистика

### Доставка

Есть выбор города:
Пермь, Екатеринбург, Тюмень, Уфа, Челябинск, Казань, Москва, Сургут и другой город.

В предоставленных документах отдельной таблицы «город → стоимость доставки» не найдено. Поэтому город сохраняется в расчёте, а стоимость вводится вручную. Также доступен отдельный документный пример 230 000 ₽ из КП «Модерн 60», где город не указан.

### Фундамент

- Существующий — 0 ₽ в текущем расчёте.
- Свайно-винтовой — 220 000 ₽, документный пример из КП «Модерн 60».
- ФБС — требует согласованной стоимости.
- Локальное усиление — по расчёту КР.

### Монтаж

- Ручная согласованная стоимость.
- Бесплатная установка и монтаж до 70 км от производства — для условий, указанных в каталоге.
- 300 000 ₽ — документный пример из КП «Модерн 60».

## GitHub Pages

В `.github/workflows/deploy.yml` настроена публикация результата Vite-сборки. Старого `static.yml` в проекте нет.

```bash
npm install
npm run dev
```

Для GitHub Pages достаточно загрузить содержимое проекта в репозиторий и дождаться workflow `Deploy DP MODULE Sales to GitHub Pages`.

## Данные

КП и список клиентов в этой версии сохраняются в LocalStorage браузера. Общая база на несколько менеджеров потребует backend/БД на следующем этапе.
