# DP MODULE Sales - exact A4 CP template

Рабочая версия внутреннего конфигуратора DP MODULE.

## Коммерческое предложение

В качестве визуального шаблона используется присланное КП «Канада 24». Все 5 страниц шаблона отрендерены с исходного PDF и используются как фон без перестройки композиции.

Исходный PDF: 5 страниц, A4 (595.276 × 841.89 pt).

Генератор всегда создаёт PDF в формате A4 (210 × 297 мм).

Переменные значения накладываются только в предусмотренных областях:
- модель / проект;
- клиент;
- номер КП;
- фундамент;
- модули;
- стоимость;
- площадь;
- габариты;
- высота;
- город доставки;
- дополнительные опции.

Планировка выбранной модели подставляется в соответствующий блок страницы 3. Для повторного скачивания сохранённого КП данные конфигурации сохраняются вместе с КП.

## Кнопки

В разделе предпросмотра КП:
- Печать — печатает A4;
- Скачать КП (PDF) — скачивает готовый PDF-файл на компьютер.

В истории КП также есть кнопка «Скачать PDF» для каждого сохранённого предложения.

## Авторизация

Supabase Auth сохранена. КП и клиенты привязаны к аккаунту менеджера и доступны после входа с другого компьютера.

Файл `public/supabase-config.js` уже содержит Project URL и Publishable Key.

## GitHub Pages

```bash
npm install
npm run dev
```

Для GitHub Pages используется `.github/workflows/deploy.yml`.

### Важное исправление
`index.html` явно загружает `./supabase-config.js` до запуска React. Это обязательно для GitHub Pages, потому что конфигурация Supabase хранится в `window.DP_SUPABASE_CONFIG`.
