# DP MODULE Sales — v5

Внутренний конфигуратор отдела продаж DP MODULE для GitHub Pages.

## Основное

- Каталог домов, бань и готовых комплексов.
- Готовый проект или индивидуальная конфигурация.
- Автоматический расчёт базы + опций + доставки + фундамента + монтажа.
- Дополнительные опции для домов.
- 5-страничное коммерческое предложение по визуальной структуре предоставленного КП «Канада 24».
- Предпросмотр КП в браузере.
- Печать.
- Прямое скачивание КП в PDF на компьютер без окна печати.

## Как скачать КП

В расчёте нажмите «Предпросмотр КП», затем «Скачать КП (PDF)».
PDF собирается прямо в браузере из пяти страниц шаблона.

## GitHub Pages

В `.github/workflows/deploy.yml` используется Vite build и публикация каталога `dist`.

Старый `static.yml` использовать нельзя.
