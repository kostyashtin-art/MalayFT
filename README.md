# DP MODULE Sales — автоматический расчёт по Excel-прайсу

В этой версии расчёт дополнительных работ и опций перенесён из пользовательского файла `ПРАЙС DP-MODULE.xlsx`.

## Источники расчёта

- Базовая стоимость моделей — каталог DP MODULE.
- Дополнительные работы и опции — лист **«Доп. услуги»**.
- Варианты цен **наличные / безналичные** — из того же листа.
- Региональные цены — листы **«Прайс БРЗ + Кам-УР»** и **«Прайс НОВОСИБИРСК»**.
- Окна и двери — лист **«Прайс окна и двери (цена БРЗ + ...»**.
- Оборудование — листы по климатическому оборудованию.
- Редкие позиции сохранены отдельно и не выдаются как обычные доступные опции, если в прайсе стоит пометка об ограничении.

## Автоматические правила

- Для единичных, м², м.п., помещений и комплектов сумма = количество × цена.
- Для процентных позиций (например, увеличение высоты/утепления) сумма считается от **базовой стоимости дома без дополнительных опций**, как указано в прайсе.
- Позиции `НЕ ДЕЛАЕМ`, `ПОКА НЕ ДЕЛАЕМ`, `Нет в наличии` не предлагаются как доступные для выбора.
- Позиции с пометкой `ЦЕНА СОГЛАСОВЫВАЕТСЯ ДОПОЛНИТЕЛЬНО...` доступны только через ручную согласованную позицию.
