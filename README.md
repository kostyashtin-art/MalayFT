# DP MODULE Sales

В этой версии добавлено автоматическое сохранение текущего черновика расчёта в LocalStorage браузера. При случайном обновлении страницы или повторном открытии сайта под тем же аккаунтом незавершённый расчёт восстанавливается.

Сохраняются: проект, выбранные опции, ручные позиции, клиент, доставка, фундамент, монтаж, регион/тип цены, индивидуальный проект, номер КП и текущий экран.

Кнопка «Новый расчёт» намеренно очищает черновик.
