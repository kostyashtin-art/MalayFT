# DP MODULE Sales — clean UI

Версия с фирменным логотипом DP MODULE и минималистичным интерфейсом без лишних пояснительных блоков.

Сохранены текущие возможности проекта: каталог, конфигуратор, опции, логистика, авторизация Supabase, облачные КП/клиенты и предпросмотр КП.

Логотип из пользовательского изображения сохранён в `public/assets/dp-module-logo.png` и белая версия для тёмного фона — `public/assets/dp-module-logo-white.png`.
